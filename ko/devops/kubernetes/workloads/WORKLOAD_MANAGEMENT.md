# Workload Management

- 쿠버네티스는 워크로드 및 해당 워크로드 구성 요소를 선언적으로 관리하기 위한 여러 내장 API를 제공함
  - 궁극적으로 애플리케이션은 파드 내부에서 컨테이너 형태로 실행됨
  - 하지만 개별 파드를 직접 관리하는 것은 많은 노력을 필요로 함
    - 예를 들어, 어떤 파드에 장애가 발생하면 대게 이를 대체할 새로운 파드를 실행하기를 원함
    - 쿠버네티스가 이 작업을 자동으로 수행할 수 있음
- 사용자는 쿠버네티스 API를 사용하여 파드보다 높은 추상화 수준을 가진 워크로드 오브젝트를 생성할 수 있음을
  - 그렇게 하면 쿠버네티스 컨트롤 플레인이 사용자가 정의한 워크로드 오브젝트의 명세(Specification)을 기반으로 파드 오브젝트들을 자동으로 관리함
